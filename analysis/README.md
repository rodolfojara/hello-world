# Analysis

This directory contains the repository owner's exploratory analysis from the small-satellite tracking study.

The main notebook, `Lecturadatos.ipynb`, is currently preserved at the repository root because the GitHub file interface used for this cleanup cannot safely rename binary notebook files. It will be relocated/renamed when the repository is edited locally.

The notebook should be understood as historical exploratory work: reading and plotting stellar coordinate lists and experimenting with coordinate transformations. It is not presented as a complete star-tracker implementation.
